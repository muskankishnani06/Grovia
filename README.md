## 🚀 Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Page structure |
| CSS3 | Custom styling |
| Bootstrap 5.3 | Layout, components, utility classes |
| Swiper.js 12 | Horizontal card slider |
| Font Awesome 7 | Icons |

---

## 📄 Sections

| Section | Description |
|---|---|
| **Navbar** | Sticky pill-shaped navbar with links — About, Feature, Pricing, Contact Us |
| **Hero** | Headline, tagline, CTA buttons, overlapping UI card images |
| **Marquee** | Auto-scrolling customer/partner logos |
| **Dashboard** | Full-width dashboard preview image |
| **How It Works Slider** | 3-step Swiper.js slider — Easy Setup, Invite Team, Track Progress |
| **Features (Tabs)** | Bootstrap tab-based feature showcase with 4 UI cards |
| **Pricing** | Dark background pricing section with Bootstrap tab toggle (Monthly/Yearly) |
| **Testimonials** | 3-column staggered testimonial cards |
| **FAQ** | Bootstrap accordion for frequently asked questions |
| **Start Journey** | CTA section with contact form and customer rating |
| **Footer** | Newsletter signup, page links, social icons, email |

## ⚙️ Setup & Usage

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/grovia.git
   cd grovia
   ```

2. **Open in browser**
   ```bash
   # Simply open index.html in any browser
   open index.html
   ```
   > No build tools or npm required — this is a pure HTML/CSS/JS project.

3. **Edit content**
   - Update text and images directly in `index.html`
   - Modify colors and layout in `style.css`
